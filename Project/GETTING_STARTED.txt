❓ TROUBLESHOOTING:

"Port 5000 already in use"
   → Change port in app.py (line: app.run(port=5000))
   
"Module not found (flask, requests, etc)"
   → Run: pip install -r requirements.txt

"Browser won't open"
   → Manually open index.html in your browser
   → Make sure app.py is running

"No phones found"
   → Increase budget or remove filters

"Can't find files"
   → Make sure all files are in c:\Project
   → Check QUICK_START.txt
