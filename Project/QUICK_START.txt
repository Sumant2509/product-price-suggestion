❌ TROUBLESHOOTING:

Problem: "No phones found"
Solution: Increase budget or remove filters

Problem: "API not found" error
Solution: Make sure app.py is running on port 5000

Problem: "Python not found"
Solution: Install Python 3.8+ from python.org

Problem: "requests/BeautifulSoup not found"
Solution: Run: pip install -r requirements.txt
